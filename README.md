### Core Components

- **OS:** Fedora 44
- **Compositor:** Hyprland
- **Terminal:** Kitty
- **Shell:** Zsh
- **Dotfile Manager:** Chezmoi

## Installation

Clone and initialize the dotfiles with chezmoi:

```bash
chezmoi init git@github.com:P-mcg01/dotfiles.git
chezmoi apply
```
